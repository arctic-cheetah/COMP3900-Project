
# Junior Developer Skills & Competencies

## 1. Programming Proficiency

### Core Languages (Proficiency Level: Developing to Intermediate)

- **JavaScript / TypeScript**: Fundamental understanding of ES6+ features, basic type annotations, and asynchronous programming concepts.
- **Python**: Basic syntax knowledge for scripting tasks; familiar with fundamental constructs like functions, loops, conditionals.
- **HTML5 & CSS3**: Ability to write semantic HTML structures and apply responsive styling using Flexbox/Grid basics.

## 2. Web Technologies (Beginner Stage)

### Frontend Foundations

- Understanding of HTTP requests/responses (GET, POST, etc.)
- Basic DOM manipulation through JavaScript
- Familiarity with single-page application patterns

### Tools & Platforms

- Git: Version control workflows using `git add`, `commit`, and basic branching strategies.
- Webpack/Vite basics: File bundling concepts for static assets.
- Browser DevTools: Proficient use of Console, Network tab, and Elements inspector.

## 3. Database Literacy (Emerging)

### SQL Basics

- Ability to construct SELECT queries with WHERE conditions
- Understanding of primary keys and basic JOIN operations (INNER/LEFT JOIN).

### Modern ORMs Awareness

- Familiarity concepts from frameworks like Sequelize or TypeORM if applicable; able to execute simple CRUD patterns.

## 4. APIs & Integration (Novice)

- RESTful API design principles understanding: resources, endpoints, status codes.
- Basic HTTP client usage via `fetch` or Axios for making requests and handling responses with minimal error management.
- JWT authentication basics if exposed in coursework projects; role-based access conceptually known but unimplemented independently yet.

## 5. Methodologies & Best Practices (Learning Phase)

### Version Control Workflow

- Branching using GitHub Flow concepts: feature branches, PRs, and merging via merge commits or rebase when guided.

### Testing Fundamentals

- JEST basics if applicable; basic unit test structure with assertions for simple logic flows.

## 6. Tools & Technologies (Ad-hoc)

- **Node.js**: Basic server-side setup for a minimal API using Express framework concepts but not fully architected yet.
- Docker: Familiarity with multi-container setups and volume mounts via `docker-compose.yml`.

## 7. Continuous Learning Plan

### Q3-Q4 Goals

1. Complete beginner-friendly bootcamp curriculum focusing on full-stack basics.
2. Build two small projects (e.g., CRUD app using Firebase or Supabase backend + frontend).
3. Contribute to open source issues labeled `good first issue` in JavaScript-related repositories.

---

**Note**: This skill set reflects a junior developer's baseline competency with clear pathways to grow independently through mentorship and hands-on project work rather than advanced architectural decision-making currently reserved for lead roles. Priorities focus on building reliable small-scale applications under supervision while expanding technical breadth systematically over time.
